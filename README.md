**Employee Issue Management**

**Overview**

A ServiceNow scoped application for enabling employees to raise and manage workplace issues through Employee Center.

**Features**

Employee issue submission through a Record Producer
Issue categorization and subcategorization
Requester and state information capture
Support for categories such as Hardware, Software, Network, VPN, Server, and Access
Role-based access using ACLs
Dedicated application module for managing employee issues

**Technologies**
ServiceNow
App Engine Studio
Scoped Application
Employee Center
ServiceNow Tables, Forms, Record Producers, ACLs, Roles
GitHub Source Control

**Application Flow**

Employee
   ↓
Employee Center
   ↓
Raise Employee Issue
   ↓
Issue Details & Category
   ↓
Employee Issue Record
   ↓
Authorized Users Manage Issues

**Version Control**

The application is integrated with GitHub using ServiceNow Source Control for version management and backup of application files.

**Objective**

To provide a structured and secure way for employees to submit workplace issues and for authorized users to manage them efficiently.
